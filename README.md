# kidney-vessels

Программные средства локализации микрососудистых структур на гистологических
изображениях почек человека. Первый этап: основа Python-приложения и аудит исходных
данных **HuBMAP — Hacking the Human Vasculature (2023)**.

Приложение читает тайлы, JSONL и метаданные, проверяет изображения и геометрию,
сохраняет реестры, статистику, диагностику и контурные примеры. Оно пока не обучает
нейросеть и не выполняет предсказания. Архитектура не фиксирует детекцию/сегментацию,
число классов или формат будущих результатов.

**Реальный HuBMAP в репозитории отсутствует. Приёмка выполнена на синтетических
данных; это не аудит настоящих медицинских изображений.**

## Установка

Нужны Git и [uv](https://docs.astral.sh/uv/getting-started/installation/).
Зафиксированный Python: 3.12; поддерживается `>=3.12,<3.13`.
Команды ниже выполняются из корня проекта в PowerShell; активация venv не нужна.

```powershell
uv python install 3.12
uv sync --locked
uv run --locked kidney-vessels --help
```

`uv.lock` фиксирует прямые и транзитивные зависимости с хешами. `pyproject.toml`
описывает допустимые диапазоны; `uv sync --locked` не обновляет lock-файл.
Для намеренного обновления: `uv lock --upgrade`, затем все проверки и коммит lock-файла.
Приёмка текущего этапа: Python 3.12.16, uv 0.13.6 на Windows.

Для установки только приложения: `uv sync --locked --no-dev`.
Без uv можно установить пакет через `py -3.12 -m pip install .`, но эта команда
сама по себе **не** фиксирует транзитивные зависимости из uv.lock.

## Запуск на искусственных данных

```powershell
uv run --locked python scripts/create_synthetic_dataset.py --output data/synthetic/hubmap
uv run --locked kidney-vessels audit --input data/synthetic/hubmap --output reports/synthetic
```

Откройте `reports/synthetic/audit.md` и `reports/synthetic/examples/*.png`.
Генератор создаёт геометрические рисунки с фиксированным seed, а не имитацию
клинического исследования. Уже непустые каталоги генератор и аудит не перезаписывают;
для следующего запуска задайте новый output.

Альтернативный запуск CLI:

```powershell
uv run --locked python -m kidney_vessels audit --input data/synthetic/hubmap --output reports/another-run --examples 3
```

## Подключение настоящего HuBMAP

Получите файлы со [страницы конкурса](https://www.kaggle.com/competitions/hubmap-hacking-the-human-vasculature/data)
с учётом условий доступа и использования. Автоматическое скачивание, учётные данные
Kaggle и принятие условий в приложение не включены. Распакуйте файлы:

```text
data/raw/hubmap/
├── train/
│   ├── <id>.tif
│   └── ...
├── polygons.jsonl
├── tile_meta.csv
└── wsi_meta.csv
```

```powershell
uv run --locked kidney-vessels audit --input data/raw/hubmap --output reports/hubmap --examples 6
```

Пути с пробелами заключайте в кавычки. Допускаются `.tif`, `.tiff`, `.png`, `.jpg`,
`.jpeg`, расширение нечувствительно к регистру. `train` читается без рекурсии;
многостраничные файлы отклоняются как неподходящие для тайлов.
Тестовая часть конкурса не требуется, лишние строки tile_meta сохраняются.

Параметры: `--examples N` (по умолчанию 6; 0 отключает PNG), `--verbose`, `--strict`.
Коды завершения: **0** — отчёт сформирован (в нём могут быть ошибки данных),
**1** — `--strict` и обнаружены ошибки уровня error, **2** — ошибка запуска,
структуры или записи отчёта. Предупреждения о неполной разметке сами по себе не дают код 1.
При сбое записи каталог может содержать частичные артефакты; используйте новый output.

## Отчёты

| Артефакт | Назначение |
|---|---|
| `images.csv` | Файлы, размеры, WSI, Dataset, состояние разметки, метаданные |
| `annotations.csv` | Все объекты, исходная категория/JSON, площадь, bbox, диагностика |
| `registry.json` | Полные реестры, исходные строки JSONL, включая повреждённые, все строки CSV |
| `summary.json` | Счётчики изображений/объектов/WSI/категорий и проблем |
| `geometry_statistics.csv`, `.json` | Число, min/max/mean/median площади и bbox по категориям |
| `issues.csv`, `.json` | Ошибки и недостающие метаданные с кодами и строками |
| `manifest.json` | Параметры, версии, входные SHA-256, системы координат, легенда PNG |
| `audit.md`, `examples/*.png` | Человекочитаемый отчёт и примеры контуров |

Все результаты пишутся в пользовательский output. `data/`, `reports/`, окружения,
бинарные документы, логи и секреты исключены из Git. Отчёты содержат исходные метаданные:
обращаться с ними следует по условиям доступа к данным.

## Проверки и сборка

```powershell
uv run --locked pytest
uv run --locked ruff check .
uv run --locked ruff format --check .
uv run --locked mypy
uv build
```

Тесты создают маленькие TIFF/JSONL/CSV во временном каталоге и не требуют скачивания
HuBMAP, GPU, PyTorch или доступа к сети. Если среда ограничивает системный TEMP,
перед pytest задайте временный каталог внутри проекта:

```powershell
New-Item -ItemType Directory -Force .cache/tmp | Out-Null
$env:TEMP = "$PWD/.cache/tmp"
$env:TMP = $env:TEMP
uv run --locked pytest
```

CI запускает эти проверки на Windows и Linux с Python 3.12.
Правила веток, коммитов и Pull Request описаны в [Git Workflow](docs/git-workflow.md).

До следующего этапа нужно согласовать с руководителем детекцию или сегментацию,
один сосудистый класс или капилляры/артериолы/венулы и правила экспертной проверки.
`blood_vessel` не содержит этих трёх подтипов. `unsure` нельзя автоматически назначать
целевым сосудистым классом. Отсутствие полигонов не доказывает отсутствия сосуда.
После подключения реальных файлов следует провести аудит, проверить контуры с
экспертом и спроектировать разбиение по WSI/пациентам до обучения.
