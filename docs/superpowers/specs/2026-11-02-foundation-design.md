# Основа проекта и аудит HuBMAP

Пользователь поручил самостоятельно реализовать законченный этап по подробной
спецификации. Дополнительные согласования проектирования не требуются.

Выбран небольшой модульный пакет с src-структурой. Монолитный сценарий затруднил бы
тестирование, а универсальная ML-платформа добавила бы преждевременные зависимости.
Доменные frozen dataclass описывают изображение, происхождение, координаты, масштаб,
категорию и аннотацию. Они зависят только от стандартной библиотеки.

Модули data читают CSV/JSONL и TIFF, annotations проверяет полигоны через Shapely,
preprocessing формирует производные RGB-копии для просмотра через Pillow,
application связывает данные и записывает аудит, CLI управляет запуском через argparse.
Исходные файлы не изменяются; полные JSON-записи и строки CSV сохраняются в реестрах.
Интерфейсы и базовые классы без заменяемых реализаций не вводятся.

Dataset 1: экспертно проверено, полнота неизвестна. Dataset 2: без экспертной проверки,
разреженная разметка. Dataset 3: неразмеченный набор. Наличие/пустота/отсутствие/ошибка
записи аннотаций учитываются отдельно. unsure не становится целевой меткой.
Неизвестные категории сохраняются и отмечаются предупреждениями.

Формат проверен 2026-11-02 по реальным CSV публичного репозитория и коду обработки
исходного JSONL; полного исходного polygons.jsonl и изображений в проекте нет.
Подробные ссылки и границы проверки приведены в docs/dataset-audit.md.

Ошибки отдельных записей попадают в реестр проблем; невалидные объекты сохраняются,
но исключаются из геометрической статистики. Ошибки структуры каталога/CSV прекращают
запуск. Аудит формирует CSV, JSON, Markdown и PNG с воспроизводимым manifest.

Приёмка: чистая установка Python 3.12, pytest, Ruff, mypy, сборка wheel и запуск
установленной CLI на синтетическом наборе; просмотр PNG. Нейросети, обучение,
маски, детекции и окончательная онтология сосудов в этот этап не входят.
